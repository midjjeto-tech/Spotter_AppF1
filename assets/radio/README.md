# Портреты говорящих (карточка рации)

Файлы отсюда отдаются как `/assets/radio/<имя>` (`web_server.py::api_radio_portrait`)
и попадают в EXE через `SpotterApp.spec` (`datas`).

**Наличие файла необязательно.** Если портрета нет, сервер отвечает 404, а карточка
рисует круг с инициалами — это штатный путь, а не поломка (ТЗ §5). Поэтому папка
может быть пустой, и приложение от этого не страдает.

## Ожидаемые имена

Имя файла задаётся в `core/radio/speakers.py` полем `portrait`:

| Файл | Кто |
|---|---|
| `engineer.webp` | ИГОРЬ ВОЛКОВ — RACE ENGINEER |
| `spotter.webp` | СПОТТЕР — TRACKSIDE SPOTTER |
| `analyst_tv.webp` | АНДРЕЙ КОРШУНОВ — RACE ANALYST (персона `tv`) |
| `analyst_hype.webp` | ГЛЕБ ЯРЦЕВ — RACE ANALYST (персона `hype`) |
| `analyst_calm.webp` | ЛЕВ ТИХОНОВ — RACE ANALYST (персона `calm`) |
| `analyst_toxic.webp` | МАРК ЗУБОВ — RACE ANALYST (персона `toxic`) |

У пилота портрета нет намеренно: его реплика — строка запроса, а не передача.

## Требования к изображению

- 256×256, WebP или PNG;
- прозрачный либо тёмный фон — карточка накладывает нижний градиент;
- кадрирование по грудь, лицо не по центру кадра, а чуть выше;
- **только оригинальные изображения.** Реальных людей, реальных инженеров F1,
  логотипов F1 и ассетов сторонних модов здесь быть не должно.

Добавление файла не требует правок кода — достаточно положить его сюда с нужным
именем и пересобрать EXE.
