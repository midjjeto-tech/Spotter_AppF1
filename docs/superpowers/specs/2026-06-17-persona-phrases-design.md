# Persona-aware шаблонные фразы — Design Spec

**Дата:** 2026-06-17  
**Статус:** Approved

---

## Проблема

`templates.render()` не знает о текущей персоне — все 4 персоны (tv/hype/calm/toxic)
получают одинаковые фразы в шаблонном режиме. Голос меняется (спикер Silero), но
слова — нет. Эффект от смены персоны ощущается только при включённом LLM.

---

## Решение

**Подход C:** `SIMPLE` остаётся базой (tv-стиль + нейтральные события).
Добавляется `PERSONA` — словарь перекрытий для hype/calm/toxic.
`render()` принимает `persona` и ищет в `PERSONA` первым.

---

## Затронутые файлы

| Файл | Изменение |
|------|-----------|
| `commentator/templates.py` | добавить `PERSONA`, обновить сигнатуру `render()` |
| `commentator/brain.py` | передать `self.persona` в `templates.render()` |

Никаких других изменений. `engine.py`, `voice/tts.py`, кэш — не трогать.

---

## Покрытие событий

Per-persona фразы: **7 ярких событий** — OVTK, RCWN, RTMT, PENA, CHQF, SSTA, FTLP.  
Нейтральные (SPTP, DRSE, DRSD, STLG, FLBK, SEND) — берутся из `SIMPLE` без изменений.

---

## Архитектура

```python
# templates.py

SIMPLE = { ... }  # tv-стиль + нейтральные — не меняется

PERSONA = {
    "hype": {
        "OVTK": [...],   # 5-6 фраз
        "RCWN": [...],
        ...
    },
    "calm": { ... },
    "toxic": { ... },
    # "tv" отсутствует — tv берётся из SIMPLE
}

def render(event: dict, persona: str = "tv") -> str:
    code = event["event_code"]
    # BATTLE имеет приоритет над персоной (нейтральный интенсив)
    if event.get("battle") and code in BATTLE:
        pool = BATTLE[code]
    else:
        pool = PERSONA.get(persona, {}).get(code) or SIMPLE.get(code)
    if not pool:
        return event.get("description", code)
    template = random.choice(pool)
    try:
        return template.format(
            driver=event.get("driver", "пилот"),
            target=event.get("target", "соперника"),
            team=event.get("team", ""),
        )
    except KeyError:
        return template
```

```python
# brain.py — единственное изменение

return templates.render(event, self.persona)  # было: templates.render(event)
```

## Данные и поток

```
engine.apply_settings({"persona": "hype"})
  → commentator.persona = "hype"
  
commentary_thread → commentator.create(event)
  → templates.render(event, "hype")
  → PERSONA["hype"].get("OVTK") or SIMPLE["OVTK"]
  → random.choice(pool).format(driver=..., target=...)
```

`BATTLE` — не меняется (используется только для OVTK при battle=True;
battle-фразы нейтральны по тону, это нормально).

---

## Что не меняется

- `SIMPLE` — без изменений
- `BATTLE` — без изменений
- `engine.py` — без изменений
- `voice/tts.py`, кэш, прогрев — без изменений
- Сигнатура `render()` — обратно совместима (`persona` опциональный с дефолтом `"tv"`)

---

## Тест-план

1. Запустить `commentator.create({"event_code": "OVTK", "driver": "Ферстаппен", "target": "Хэмилтон"}, persona="toxic")` — убедиться что возвращает фразу из PERSONA["toxic"]["OVTK"]
2. То же с `persona="tv"` — должен вернуть из SIMPLE["OVTK"]
3. Нейтральное событие (`SPTP`) с `persona="hype"` — должен вернуть из SIMPLE["SPTP"]
4. Неизвестная персона (`persona="unknown"`) — должен вернуть из SIMPLE (fallback)
