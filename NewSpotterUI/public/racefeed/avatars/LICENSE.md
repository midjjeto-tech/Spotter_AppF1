# RaceFeed avatars

These SVG files were generated with the DiceBear HTTP API using the
**Avataaars** style and stable RaceFeed persona seeds.

- Source: https://www.dicebear.com/styles/avataaars/
- API: https://www.dicebear.com/how-to-use/http-api/
- License: free for personal and commercial use

The files are stored locally so the RaceFeed UI does not depend on network
access while a race is running.
