# Spotter App

Русскоязычный ИИ-инженер, споттер и комментатор для **F1 25**. Приложение
слушает телеметрию игры по UDP и говорит голосом: предупреждает о машине
рядом, ведёт по стратегии, отвечает на вопросы по рации и комментирует гонку.

Работает рядом с игрой отдельным окном плюс прозрачный оверлей поверх F1.
SimHub не нужен.

---

## Что нужно

- Windows 10/11
- F1 25 (в том числе с Season Pack 2026)
- Ничего больше — голос и реплики работают сразу после установки

## Установка

1. Запустите `SpotterApp-Setup-*.exe`. Установщик ставит приложение в профиль
   пользователя — права администратора не нужны.
2. Оставьте отмеченным компонент **«Офлайн-голос Piper»**: без него говорить
   будет встроенный голос Windows, который звучит заметно хуже. Компонент
   занимает большую часть размера установщика, и его можно доставить позже,
   запустив установщик ещё раз.
3. При первом запуске откроется мастер настройки: он **сам проверит**, идут ли
   пакеты из игры, слышно ли голос, и подскажет, что включить.
4. В игре: **Настройки → Телеметрия → UDP-телеметрия: Вкл.**, IP `127.0.0.1`,
   порт `20777`, частота 30–60 Гц.

Если Windows покажет предупреждение SmartScreen — приложение не подписано
сертификатом (подпись стоит денег и на этом этапе её нет). «Подробнее» →
«Выполнить в любом случае».

## Работает ли без ключей

Да. Это не демо-режим с ограничениями:

| | Без ключей | С ключами |
|---|---|---|
| Реплики | заготовленный банк формулировок (86 ситуаций, три характера инженера) | GigaChat пишет под конкретный момент гонки |
| Голос | офлайн-синтез Piper, 2 русских голоса (если компонент установлен, иначе системный голос Windows) | нейросетевой голос Yandex SpeechKit |
| Вопросы по рации | — | распознавание речи Yandex |
| Спонтанные реплики между событиями | молчит | говорит |

Всё остальное — споттер, стратегия, оверлей, разбор после гонки, история
сезона — работает одинаково.

Ключи бесплатные или почти бесплатные:
- **GigaChat** (реплики): developers.sber.ru → GigaChat API → «для физических лиц»
- **Yandex Cloud** (голос и распознавание): нужен каталог и API-ключ

Вводятся в мастере настройки или в «Настройки → Yandex Cloud / GigaChat».

## Какие данные уходят наружу

**Без ключей — ничего.** Приложение не отправляет никуда ни телеметрию, ни
статистику использования, и не обращается ни к одному стороннему источнику
данных: справочники пилотов и эталоны времён лежат внутри него, а сравнение
темпа считается по самой игре и по вашему архиву заездов.

С ключами в облако соответствующего провайдера уходит:
- короткая сводка момента гонки (позиции, круг, разрывы, состояние шин) — чтобы
  сгенерировать реплику;
- текст ваших реплик по рации и их аудиозапись — чтобы их распознать;
- текст фраз — чтобы их озвучить.

Ключи хранятся только на вашем компьютере, зашифрованные средствами Windows
(DPAPI) — их нельзя прочитать под другой учётной записью. Никакой телеметрии,
аналитики и «отправки отчётов об ошибках» в приложении нет.

## Что приложение НЕ делает

- **Не управляет игрой.** Инженер может предложить заехать в боксы и услышать
  ваше «да» — но в боксы машину заводите вы. Приложение не нажимает кнопки.
- Не меняет файлы игры, не является модом и не даёт преимущества в онлайне.
- Не работает с F1 24 и старше — раскладка UDP-пакетов другая.

## Если что-то не работает — один отчёт вместо переписки

Приложение умеет само рассказать, что у него внутри. Перед заездом включите
журнал — в `settings.json` поставьте `"field_diagnostics": true` (или запустите
с переменной окружения `SPOTTER_DIAG=1`), проедьте несколько кругов, закройте
приложение и выполните:

```
.venv\Scripts\python.exe tools/diagnose.py
```

Скрипт напечатает отчёт из десяти пунктов — телеметрия, трасса, сигнал коуча,
каждая его фаза, положение в поле, причины молчания, ошибки — и у каждого пункта
будет вердикт: ОК, ВНИМАНИЕ, ПРОБЛЕМА или НЕТ ДАННЫХ, с цифрами и советом, что
делать. Рядом ляжет файл `spotter-diagnostic-<дата>.txt`; его достаточно
приложить целиком.

Журнал по умолчанию выключен: он пишет распределения сигналов на каждом кадре и
нужен только на время разбора.

## Известные ограничения

- Поддержка iRacing начата, но не закончена: переключателя в интерфейсе нет,
  библиотека `pyirsdk` в сборку не входит.
- Сравнения с реальными Гран-при больше нет. Эталон темпа в гонке — быстрейший
  круг соперников в этой же сессии, а разбор в архиве сравнивает заезд с вашим
  же лучшим на той трассе. Прежний источник (данные реальной Формулы-1) убран:
  его условия запрещали коммерческое использование. Побочный эффект скорее
  приятный — сравнивать стало корректнее: одна физика, одна погода, один
  регламент.
- Разбор в архиве требует минимум двух заездов на трассе: одному сравниваться
  не с чем.
- Голосовые клипы кэшируются на диск (`tts_cache/`) — папка растёт, её можно
  удалять целиком в любой момент.
- Порт `20777` — общий для всех телеметрийных утилит. Если его уже занял
  SimHub, Pits n' Giggles или вторая копия Spotter, мастер настройки скажет
  об этом прямо; закройте конкурента, приложение подхватит порт само.
