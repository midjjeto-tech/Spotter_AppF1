Лого Spotter App — выбери иконку для заголовка

Сейчас стоит абстрактный ромб. Вот 4 варианта с разным смыслом.

A — ТЕКУЩИЙ
Spotter App
Слои данных
Абстрактные слои — телеметрия, данные. Нейтрально, технично. Нет связи с F1.
B — РАДИО / СПОТТЕР
Spotter App
Микрофон-споттер
Споттер в F1 — человек с рацией. Прямая метафора приложения: слушай, говори.
C — МИШЕНЬ / СКАН
Spotter App
Прицел / радар
Spot = засечь, отследить. Прицел / HUD — тема слежения за трассой. Выглядит как техно-HUD.
D — МОЛНИЯ / СКОРОСТЬ
Spotter App
Молния — скорость
Молния = скорость F1 + мгновенная реакция споттера. Лаконично, узнаваемо.
